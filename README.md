# Hydroponic Plant Monitoring System Using IoT
Hydroponics is a method of growing plants without soil by using a nutrient-rich water solution. This project uses the Nutrient Film Technique (NFT), where a continuous flow of nutrient water passes through channels and reaches the plant roots. Sensors are used to monitor parameters such as pH level, water temperature, TDS, and water level. The collected data is sent to a cloud platform and mobile application for monitoring and control. This system helps maintain optimal growing conditions, ensuring healthy plant growth and efficient water and nutrient usage.
## Requirement 
### Software :
* Arduino IDE
* ThindSpeak IoT Cloud Platform
* Proteus Software
### Hardware :
* Arduino UNO Board
* DS18B20TemperatureSensor
* FloatSwitch
* TDSsensor
* pHsensor
* Relay
* WaterPumpMotor
* LCD Display 16 x 2 
## Usage
* IoT-Based Smart Agriculture: Enables real-time monitoring and control of hydroponic farming parameters using internet-connected sensors and cloud platforms.
* Embedded Systems Application: Demonstrates the use of microcontrollers for sensor interfacing, data processing, and actuator control.
* Smart Greenhouse Automation: Can be incorporated into greenhouse systems for intelligent irrigation and nutrient management.

## Future Enhancements 
The nutrients to plants can be fed automatically by connecting the nutrition
pump. This pump can be switched on and off according to the need for
nutrition based on the values of EC and pH sensors.
* The System can be designed to recycle the water that is not used by plants.
* The system can sense any impurities in the water and purify to make it safe
for the plants.
* We can add an artificial lighting system to compensate for the unavailability
of proper sunlight. Its intensity can be monitored with the help of a lumi
nosity sensor. This way the plants can also be grown indoors in the absence
of sunlight by maintaining the artificial light density.
Further, This system can be developed or modified by adding Artificial Intelligence
and Image processing
